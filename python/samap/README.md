# SAMap workflow

The repository contains two related SAMap analyses.

## 1. Broad cell-type SAMap

The broad analysis retains the following intestinal cell classes where present:

- Fibroblasts
- SMCs
- Endothelial
- Epithelial

Selected highly abundant populations are reproducibly downsampled before
export so that extreme differences in cell number do not dominate the
alignment. Not every species contains every broad cell class.

Preparation:

```text
R/cross_species/prepare_samap_celltypes.R
        ↓
R/cross_species/export_for_samap.R
        ↓
python/samap/make_h5ad.py
        ↓
notebooks/SAMap_celltype_analysis.ipynb
```

This analysis is used to inspect whether comparable broad cell classes align
across species and to obtain fibroblast-to-fibroblast GenePairFinder edges in
the context of the broader intestinal cell atlas.

The notebook also contains generalized code for:

- mapping-score calculation;
- combined and species-separated species UMAPs;
- combined and species-separated cell-type UMAPs;
- source-expression gene overlays with exact feature-name checks;
- separate 99th-percentile-scaled expression panels;
- combined 0–1 within-species relative-expression UMAPs;
- GenePairFinder + BLAST pairwise tables;
- fibroblast cross-species gene-network construction;
- connected-component summaries;
- exact species-combination tables;
- UpSet plots;
- individual gene-network visualization; and

## 2. Fibroblast-only SAMap

The fibroblast-only analysis uses the fibroblast objects generated by the
species scripts:

```text
outputs/<species>_fibroblasts.rds
        ↓
R/cross_species/export_for_samap.R
        ↓
python/samap/make_h5ad.py
        ↓
notebooks/SAMap_fibroblast_analysis.ipynb
```

The public notebook includes:

- species plots together and separately on the shared SAMap UMAP;
- exact homolog/paralog feature-name checks;
- homolog/paralog expression from species-specific SAM objects in separate 99th-percentile-scaled panels;
- combined homolog/paralog expression on a 0–1 within-species scale;
- one global Leiden clustering on the integrated SAMap graph;
- species composition of global Leiden clusters;
- species-specific marker ranking within global clusters; and
- projection of the original Seurat cluster assignments onto the SAMap UMAP.

Marker identities and unpublished biological interpretations are not committed.

## Shared Python functions

Reusable post-processing and plotting functions are stored in:

```text
python/samap/samap_analysis_utils.py
```

This module consolidates the plotting and post-processing functions that were
previously spread across exploratory notebooks.

## H5AD conversion

`python/samap/make_h5ad.py` converts the Matrix Market export from R into
AnnData. R writes genes x cells, whereas AnnData stores cells x genes, so the
matrix is transposed during conversion.

## Protein FASTA preparation

`python/samap/longest_protein_gene_symbols.py` retains one representative
protein sequence per gene (the longest isoform) and rewrites the FASTA header
to the gene symbol used in the single-cell expression matrix.

## Sequence maps

SAMap's own `map_genes.sh` is an external dependency and is **not presented as
original project code**.

The wrapper in:

```text
scripts/run_samap_blast.sh
```

runs that external script across all unique species pairs.

Example:

```bash
MAP_GENES=/path/to/SAMap/map_genes.sh \
  bash scripts/run_samap_blast.sh
```

Generated maps, processed AnnData objects, tables, figures, and unpublished
results are excluded from version control.

## Reproducibility and configuration

Shared species names, file locations, balancing caps, and analysis parameters
are defined once in:

```text
config/samap_config.json
```

Both notebooks run input checks before SAMap starts and store the parameters
and package versions used for each run under the workflow's `metadata/`
directory.

Generated outputs follow:

```text
outputs/samap_results/
├── celltype/
│   ├── objects/
│   ├── tables/
│   ├── figures/
│   └── metadata/
└── fibroblast/
    ├── objects/
    ├── tables/
    ├── figures/
    └── metadata/
```

The notebooks are intentionally kept as high-level workflows; reusable
plotting, validation, network, gene-matching, and paralog-substitution logic
lives in `samap_analysis_utils.py`.
